# PulseVerify - Android Native App

**Real-Time Physiological Deepfake Detection for Android**

Native Android implementation using MediaPipe Face Mesh and real-time rPPG signal processing.

## ✅ Project Complete - Ready to Build!

All components are implemented and ready:
- ✅ Signal processing algorithms ported to Kotlin
- ✅ MediaPipe Face Mesh integration
- ✅ CameraX pipeline
- ✅ Material Design UI
- ✅ Trust timeline visualization
- ✅ Hot-swap attack detection

## 🚀 Next Steps

1. **In Android Studio**: Click **Build → Rebuild Project**
2. Wait for build to complete (~2 minutes)
3. Connect your Android device via USB
4. Click Run ▶️

## 📱 What You'll Get

The app will show:
- Camera preview with face tracking
- 3 colored ROI boxes (red forehead, cyan cheeks)
- Real-time confidence score (0-100%)
- Heart rate (BPM)
- Status: VERIFIED / UNCERTAIN / SUSPICIOUS
- Trust timeline graph
- Signal quality metrics

## 🧪 Quick Test

1. Tap "Start Verification"
2. Face the camera in good lighting
3. Hold still for 3-5 seconds
4. Watch confidence climb to 70-95%
5. Try holding up a photo → confidence drops to <30%
